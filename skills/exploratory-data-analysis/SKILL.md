# 探索性数据分析（EDA）

系统化探索数据集，形成可复核的数据画像与下一步分析建议。

## 何时使用

- 刚拿到一份 CSV / Excel / Parquet / 查询结果
- 需要了解字段含义、质量与分布，再决定建模或报表方向
- 用户要求「先看看数据」或「做个数据概览」

## 工作流程

1. **确认输入**：数据路径、格式、业务问题（如有）、主键/时间字段候选。
2. **结构概览**：行数、列数、字段类型、样例行；识别 ID / 时间 / 类别 / 数值字段。
3. **质量检查**：缺失率、重复行、异常值与不可能取值、单位不一致。
4. **单变量分布**：数值字段的中心趋势与离散度；类别字段的频次与长尾。
5. **关系探索**：关键相关、分组对比、时间趋势（如有时间列）。
6. **交付洞察**：用简洁条目列出发现、风险与建议的下一步分析。

## 输出要求

按以下结构回复（可用表格）：

```markdown
## 数据画像
- 规模 / 主键候选 / 时间范围

## 字段一览
| 字段 | 类型 | 缺失率 | 备注 |

## 关键发现
1. ...

## 数据质量风险
- ...

## 建议的下一步
- [ ] 清洗：...
- [ ] 可视化：...
- [ ] 统计检验 / 建模：...
```

## 原则

- 先描述事实，再给解释；区分「观察到的」与「推测的」。
- 不擅自删除或改写原始数据；清洗建议单独列出。
- 大数据集优先抽样或聚合后再探索，并说明抽样方式。
- 需要详细清单时，再读 [references/eda-checklist.md](references/eda-checklist.md)。

## 脚本

```bash
node scripts/profile-csv.mjs --file ./data.csv --keys 主键字段 --out /tmp/profile.json
```
