## 1. 背景

本文档约束从**原始数据接收 → 整理清洗 → 指标拆解 → 多维分析 → 可视化 → 结论建议 → 报告归档**的全套工作流程。

设计原则：

- **可复现**：原始只读、规则留痕、指标可回溯明细  
- **可验收**：每阶段有完成定义（DoD）与交付物  
- **可决策**：结论有数据支撑，建议可落地可量化  
- **可安装**：流程拆解为 Agent Skills，便于团队与 AI 代理统一执行  

---

## 2. 目标（本次要做）

- [ ] 完成原始数据接收、备份、完整性校验  
- [ ] 完成数据整理、结构化、标准化清洗，输出干净可用的分析数据集  
- [ ] 基于业务需求完成分析目标拆解、指标体系搭建、衍生指标计算  
- [ ] 开展大盘、结构、趋势、对比、归因、二八等多维度数据分析  
- [ ] 按可视化规范输出全套图表素材  
- [ ] 输出现状 / 亮点 / 问题结论，以及可落地、可量化的优化建议  
- [ ] 输出完整结构化数据分析报告  
- [ ] 底稿、数据集、图表、口径文档统一归档交付  

---

## 3. 非目标（本次不做）

- ❌ 机器学习预测、建模训练、AI 预测模型开发  
- ❌ 改造业务数据库、新增/修改埋点  
- ❌ 开发数据看板、后台系统程序  
- ❌ 输出没有数据支撑的主观猜想、臆断结论  
- ❌ 私自修改团队统一指标口径  
- ❌ 对外输出未脱敏的敏感原始业务数据  

若需求落入非目标，应单独立项，不在本 Spec 范围内硬做。

## 4. 输入物料（前置依赖）

| # | 物料 | 必需 | 说明 | 缺失时处理 |
|---|------|------|------|------------|
| 1 | 原始数据集 | 是 | CSV / Excel / 库表导出明细 | **阻断** |
| 2 | 业务需求文档 | 是 | 主题、周期、对象、关注重点 | **阻断** |
| 3 | 对标基准 | 视主题 | 上期、去年同期、目标、行业基准 | 降级：不做完成率/同比相关结论 |

## 5. 详细执行流程

每小节含：**步骤 → 完成定义（DoD）→ 交付物 → 常见坑**。  
阶段模板见 `docs/templates/`。

### 5.1 数据接收 & 存档校验

**Skill：** `data-intake`

#### 步骤

1. 原始文件**禁止直接修改**；复制备份，命名：`原始数据_未处理_YYYYMMDD[.来源].csv/xlsx`  
2. 校验：时间区间完整度、字段齐全度、文件无损坏/乱码、无重复导出冗余  
3. 登记元信息：来源、导出时间、提供人、统计周期、总行数、文件大小/编码  

#### DoD

- [ ] 备份存在且与原始字节一致（或记录校验和）  
- [ ] 元信息台账填写完整  
- [ ] 校验结论为「通过」或「阻断 + 待办」已书面确认  

#### 交付物

- 备份文件 + 元信息台账（可用 `docs/templates/01-meta-intake.md`）

#### 常见坑

- 直接在业务发来的文件上改数 → 无法审计  
- 多份「最终版」并存未标版本 → 后续口径混乱  

---

### 5.2 数据整理｜结构化规整

**Skill：** `data-structuring`

#### 步骤

1. 清理表格：合并单元格、多余标题行、备注行、页脚、空行空列  
2. 表头标准化：统一中文列名（或字典名），去特殊符号/空格/换行  
3. 格式统一：  
   - 日期 → `YYYY-MM-DD`  
   - 数值 → 纯数字（去货币符、千分位）  
   - 文本 → 去首尾空格与不可见字符  
4. 多源多表：按关联键合并宽表，保留 `数据来源` 字段；记录一对多膨胀  

#### DoD

- [ ] 每列类型明确，无「整列变文本的数字」未说明原因  
- [ ] 字段映射表完整（原名 → 标准名）  
- [ ] 合并键与行数变化可解释  

#### 交付物

- 结构化中间集 + 字段映射表（`docs/templates/02-field-mapping.md`）

#### 常见坑

- Excel 序列号日期未转换  
- 隐式类型转换导致 ID 精度丢失（长数字当 float）  

---

### 5.3 数据清洗规则

**Skill：** `data-cleaning`

#### 缺失值

| 情形 | 处理 |
|------|------|
| 业务关键字段缺失 | 剔除该行，日志记剔除行数 |
| 非关键字段缺失 | 标记 `[缺失]`，不参与对应指标统计 |
| 全表 | 统计各字段缺失率 → 写入报告「数据说明」 |

#### 重复值

- 按唯一主键校验；重复保留**最新一条**有效记录  
- 统计重复条数与占比 → 清洗日志  

#### 异常值

- 识别：不合理 0、极端值、未来时间、过期脏数据  
- 原则：**优先标记隔离并备注，不直接暴力删除**  
- 严重脏数据确认后剔除，留存剔除记录  

#### 脏数据 & 口径统一

- 清乱码、换行、异常符号  
- 维度值按字典映射（渠道、地区、业务状态等）  
- 状态码/分类与官方字典对齐  

#### 一致性校验

- 明细求和 ≈ 汇总  
- 同比/环比/层级逻辑不自洽 → 标记并核查  

#### DoD

- [ ] 清洗日志覆盖缺失/重复/异常/映射/一致性  
- [ ] 输出清洗完成数据集（衍生可下一步）  
- [ ] 高风险删除已获确认或书面豁免  

#### 交付物

- 清洗集 + 清洗日志（`docs/templates/03-cleaning-log.md`）  
- 命名参考：`数据集_清洗完成_YYYYMMDD.xlsx`；带衍生后：`数据集_清洗完成_带衍生字段_YYYYMMDD.xlsx`

#### 常见坑

- 静默删行导致大盘对不上  
- 「最新一条」未定义排序键（应用业务时间，而非文件行号）  

---

### 5.4 衍生字段 & 指标扩充

**Skill：** `derived-metrics`

#### 必须覆盖

1. **时间**：年、季、月、周、工作日/周末  
2. **增长**：增量、环比、同比、目标完成率  
3. **结构**：分项占比、TopN 贡献占比  
4. **统计**：均值、中位数、极差、渗透率  
5. **分层**：高/中/低价值；头–腰–尾  

#### DoD

- [ ] 每个衍生字段有公式/规则与依赖字段  
- [ ] 分层阈值有业务依据或已标注默认规则待确认  
- [ ] 边界情况（分母为 0、基期缺失）有处理说明  

#### 交付物

- 带衍生字段数据集 + 衍生字段清单（可并入口径附录）

---

### 5.5 分析目标拆解

**Skill：** `analysis-decomposition`

#### 固定四向（原则上全覆盖）

1. **大盘整体**：总量规模、整体趋势、目标完成  
2. **结构拆解**：渠道/产品/用户/区域结构与贡献  
3. **趋势 & 异动**：周期波动、峰谷、涨跌定位  
4. **分层对比**：同期、上期、群体/渠道横向  

#### DoD

- [ ] 四向均有：问题、指标、维度、对比基准、产出物  
- [ ] 数据不足的方向已标注「无法覆盖 + 原因」  

#### 交付物

- 分析提纲（`docs/templates/04-analysis-outline.md`）

---

### 5.6 核心指标计算与校验

**Skill：** `metrics-calculation`

#### 四类指标（公式必须入口径附录）

| 类别 | 示例 |
|------|------|
| 总量 | 总和、累计、订单总数、用户总数 |
| 质量 | 转化率、流失率、复购率、渗透率 |
| 增长 | 净增量、环比、同比 |
| 结构 | 分类占比、头部 20% 贡献占比 |

> 所有指标可回溯到原始明细；计算底稿留存。

#### DoD

- [ ] 口径附录完整（分子/分母/过滤/去重/时间对齐）  
- [ ] 校验：加总、占比、增长率边界  
- [ ] 抽样可回溯到明细行  

#### 交付物

- 结果表 + 口径附录 + 底稿（`docs/templates/05-metric-dictionary.md`）

---

### 5.7 多维度深度分析

**Skill：** `multidimensional-analysis`  
（探索性补充：`exploratory-data-analysis`；推断统计补充：`statistical-analysis`）

#### 必须覆盖六视角

1. 趋势  2. 结构  3. 对比  4. 相关（相关≠因果）  5. 二八  6. 异常归因（先排数据原因，再排业务原因）

#### DoD

- [ ] 六视角清单全部勾选或标注豁免原因  
- [ ] 异动归因有证据链  
- [ ] 二八与结构结论交叉验证  

#### 交付物

- 分视角发现纪要（可并入报告第 4–5 章）

---

### 5.8 数据可视化输出规范

**Skill：** `data-visualization`

#### 选型

| 目的 | 图表 |
|------|------|
| 时间趋势 | 折线 |
| 分类对比 | 柱状 / 横向条形 |
| 占比结构 | 饼 / 环 / 堆叠柱（类别多时慎用饼图） |
| 相关 | 散点 |

#### 统一格式

- 标题、Y 轴单位、统计周期、数据来源  
- 配色简洁；拐点与关键值标注  
- 原图单独归档  

#### DoD

- [ ] 图号清单与文件路径齐全  
- [ ] 图中数字与底稿一致  

#### 交付物

- 原图包 + 图表清单（`docs/templates/06-chart-inventory.md`）

---

### 5.9 结论推导规则

**Skill：** `insight-conclusion`

#### 公式

**客观数据现象 + 对比数据 + 数据支撑 + 业务解读**

#### 三类

1. 现状  2. 亮点  3. 问题  

#### DoD

- [ ] 每条结论具备四要素  
- [ ] 无「无支撑结论」  

#### 交付物

- 结论卡（`docs/templates/07-conclusion-cards.md`）

---

### 5.10 优化建议输出规则

**Skill：** `actionable-recommendations`

#### 合格标准

可落地、可执行、可量化、对应已发现问题。  

#### 禁止空泛话术

如：「加强运营」「提升意识」「优化体验」「持续关注」（无具体动作与指标时一律重写）。

#### DoD

- [ ] 每条建议可指回问题结论 ID  
- [ ] 有预期指标/观察窗口或明确「待补基线」  

#### 交付物

- 建议表（`docs/templates/08-recommendation-cards.md`）

---

### 5.11 分析报告输出结构

**Skill：** `analysis-report`

#### 固定章节

1. 摘要  
2. 数据说明（源、周期、清洗、样本）  
3. 大盘整体解读  
4. 分维度逐项分析  
5. 异动与问题归因  
6. 业务亮点  
7. 落地优化策略  
8. 潜在风险  
9. 附录：口径、公式、清洗日志  

#### DoD

- [ ] 摘要可独立阅读  
- [ ] 满足 AC-07 闭环  

#### 交付物

- 完整报告（骨架：`docs/templates/09-report-outline.md`）

---

## 6. 验收标准 AC（逐条验收）

| ID | 标准 | 证据 |
|----|------|------|
| AC-01 | 全套交付齐全 | 交付索引 6 类文件 |
| AC-02 | 缺失/重复/异常按规则处理并留日志 | 清洗日志 |
| AC-03 | 指标公式透明、口径统一、可回溯 | 口径附录 + 底稿抽查 |
| AC-04 | 图表与内容匹配，无错图/缺标签 | 图表清单核对 |
| AC-05 | 结论均有数据支撑 | 结论卡四要素 |
| AC-06 | 建议可落地可量化，无空泛话术 | 建议表 |
| AC-07 | 闭环：原始数据 → 现象 → 结论 → 方案 | 报告结构走查 |

全部 AC 通过方可标记「可交付」。

---

## 7. 约束条件

1. 基于真实完整数据，不得篡改或选择性截取有利数据  
2. 清洗与指标计算操作留痕，便于复盘  
3. 口径对齐团队标准；临时口径必须标注并限期对齐  
4. 敏感数据脱敏后再对外交付  
5. 对外分享仅使用交付包版本，禁止口口相传「另一份表」  

---

## 8. 适用范围

业务专题分析、销售分析、运营复盘、用户分析、产品数据分析、月度/季度复盘、指标异动排查。

不适用：实时流式监控产品化、算法模型交付、数据平台工程（见非目标）。

```text

  05_report/              # 报告正文

```

## 12. 术语表

| 术语 | 含义 |
|------|------|
| 口径 | 指标的分子、分母、过滤、去重与时间对齐规则 |
