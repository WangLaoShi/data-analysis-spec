# 多维度深度分析（Spec 5.7）

在指标就绪后，按六个视角做深度分析；输出需能支撑结论与建议。

## 必须覆盖的视角

1. **趋势分析**：随时间变化规律、周期性波动  
2. **结构分析**：主次贡献分布，识别核心大头  
3. **对比分析**：横向组别、纵向时间  
4. **相关性分析**：外部因素、业务动作与指标波动关联（相关 ≠ 因果，需声明）  
5. **二八分析**：验证头部主体贡献占比（如头部 20%）  
6. **异常归因**：涨跌溯源，区分业务原因 vs 数据原因  

## 工作流程

1. 对照 `analysis-decomposition` 四向提纲，映射到上述六视角。
2. 每视角给出：方法、关键切片、图表/表、发现摘要。
3. 异动项建立归因树：先排数据问题（口径、漏数、重复），再排业务因素。
4. 二八与结构结论交叉验证（头部是否稳定、是否过度集中）。

## 输出

```markdown
## 视角覆盖清单
- [ ] 趋势 [ ] 结构 [ ] 对比 [ ] 相关 [ ] 二八 [ ] 异常归因

## 分视角发现
### 趋势
### 结构
### 对比
### 相关
### 二八
### 异常归因

## 交叉验证与待确认假设
```

## 原则

- 六视角原则上全部覆盖；缺数据导致无法做的视角写明原因。
- 归因先排除数据质量，再谈业务故事。
- 相关性发现不得直接写成因果结论。
