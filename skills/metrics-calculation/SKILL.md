# 核心指标计算与校验（Spec 5.6）

按四类指标体系计算，并保证口径统一、可回溯。

**模板：** `docs/templates/05-metric-dictionary.md`。

## 脚本

```bash
node scripts/check-metric-dictionary.mjs --file ./deliverables_YYYYMMDD/03_metrics/05-metric-dictionary.md
```

检查是否存在「指标」表及公式列；stdout JSON 含 `blocking` / `warnings`。

## 指标四类

1. **总量指标**：总和、累计量、订单总数、用户总数  
2. **质量指标**：转化率、流失率、复购率、渗透率  
3. **增长指标**：净增量、环比增长率、同比增长率  
4. **结构指标**：各分类占比、头部 20% 贡献占比  

## 工作流程

1. 对齐团队指标字典；禁止私自改口径（有冲突先确认）。
2. 为每个指标写清：分子、分母、过滤条件、时间对齐、去重规则。
3. 计算并留存底稿（可复现脚本或透视步骤）。
4. **校验**：
   - 明细加总 ≈ 汇总
   - 占比合计 ≈ 100%（允许舍入误差说明）
   - 增长率分母为 0 / 基期缺失的处理方式
   - 抽样回溯到原始明细行

## 输出

```markdown
## 口径附录
| 指标 | 类别 | 公式 | 过滤/去重 | 数据源字段 |

## 本期结果表
| 指标 | 本期 | 上期 | 同比/环比 | 目标 | 完成率 |

## 校验记录
- 通过项 / 差异项与原因

## 计算底稿路径
```

## 原则

- 所有指标可回溯到原始明细；底稿与结果一并交付。
- 口径变更必须先更新字典/附录，再改数。
