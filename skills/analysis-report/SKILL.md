# 分析报告输出结构（Spec 5.11）

结论在前、证据在后；串联 `insight-conclusion` 与 `actionable-recommendations` 的产出。

**模板：** `docs/templates/09-report-outline.md`。

## 固定结构

1. **摘要**：一页总结，核心发现  
2. **数据说明**：数据源、统计周期、清洗说明、样本说明  
3. **大盘整体数据解读**  
4. **分维度逐项数据分析**  
5. **异动、问题归因分析**  
6. **业务亮点总结**  
7. **分条落地优化策略**  
8. **潜在风险提示**  
9. **附录**：指标口径、计算公式、清洗日志  

## 工作流程

1. 确认读者与决策场景。  
2. 填入已有结论、建议、图表引用（给文件名/图号）。  
3. 检查逻辑闭环：原始数据 → 现象 → 结论 → 方案（AC-07）。  
4. 数字与底稿、图表交叉核对。

## 原则

- 摘要可独立阅读。  
- 结论与建议均能指回数据支撑。  
- 附录口径与正文指标名称一致。
