# 分析目标拆解（Spec 5.5）

把业务问题拆成固定四向分析提纲，再交给指标计算与多维分析执行。

**模板：** `docs/templates/04-analysis-outline.md`。

## 固定四个拆解方向

1. **大盘整体分析**：总量规模、整体趋势、目标完成情况  
2. **结构拆解分析**：渠道、产品、用户、区域结构与贡献占比  
3. **趋势 & 异动分析**：周期波动、波峰波谷、指标涨跌异动定位  
4. **分层对比分析**：同期对比、上期对比、不同群体/渠道横向对比  

## 工作流程

1. 确认主题、周期、对象、成功标准（来自需求文档）。
2. 将用户问题映射到上述四向（可标注优先级，但四向原则上都要覆盖）。
3. 每向写出：关键问题、所需指标、所需维度、对比基准、产出物（表/图）。
4. 标注依赖：缺字段 / 缺目标值 / 缺对标数据 → 列入阻断项。

## 输出

```markdown
## 分析主题与周期

## 四向提纲
### 1. 大盘整体
- 问题 / 指标 / 维度 / 产出

### 2. 结构拆解
...

### 3. 趋势 & 异动
...

### 4. 分层对比
...

## 优先级与执行顺序
## 数据与口径依赖（阻断项）
```

## 原则

- 不跳过四向中的整块；若数据不足导致无法做某向，明确写「无法覆盖 + 原因」。
- 提纲可执行：避免只有口号没有指标与维度。
