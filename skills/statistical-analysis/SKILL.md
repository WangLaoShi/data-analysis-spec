# 统计分析

用合适的统计方法回答明确问题，并诚实报告假设、效应量与局限。

## 何时使用

- 需要从样本推断总体或比较组间差异
- A/B 测试、相关、回归、方差分析等
- 用户要求「是否显著」或「有没有关系」

## 工作流程

1. **陈述问题**：总体、干预/分组、结局指标、单侧/双侧。
2. **检查假设**：独立性、分布形态、方差齐性、多重比较等。
3. **选方法**：参数 / 非参数；检验 vs 估计（优先报告效应量与区间）。
4. **执行**：可复现代码；固定随机种子（如重采样）。
5. **解读**：统计显著 ≠ 实际重要；说明实际意义与外部效度。

## 常见方法速查

| 问题 | 常用方法 |
|------|----------|
| 两组均值差 | t 检验 / Mann-Whitney；报告均值差与 CI |
| 多组均值 | ANOVA + 事后比较；注意多重比较校正 |
| 比例差 | χ² / Fisher；比例差与 CI |
| 相关 | Pearson / Spearman；散点图必看 |
| 连续结局预测 | 线性回归；残差与共线性检查 |
| 二分类结局 | Logistic；报告 OR 与校准情况 |
| A/B | 预先指标与停机规则；避免 peeking 而不校正 |

## 输出要求

```markdown
## 问题与假设
## 数据与过滤条件
## 方法与为何适用
## 结果（效应量 + 区间 + p 值）
## 结论（面向业务的一句话）
## 局限与后续验证
```

## 原则

- 先估计与可视化，再假设检验。
- 报告效应量与置信区间，不只报告 p 值。
- 预先声明主指标；探索性分析需标注为探索性。
- 小样本、多重检验、选择偏倚要明确写出。
