# 结论推导规则（Spec 5.9）

**模板：** `docs/templates/07-conclusion-cards.md`。

## 结论公式

**客观数据现象 + 对比数据 + 数据支撑 + 业务解读**

## 三类结论

1. **现状结论**：业务整体现状、大盘表现  
2. **亮点结论**：增长优势、高贡献渠道、优质用户群体  
3. **问题结论**：下滑项、低效板块、现存短板与缺口  

## 工作流程

1. 从多维分析与指标表中抽取候选发现。
2. 每条结论补齐四要素；缺对比或缺支撑的降级为「观察」而非「结论」。
3. 区分事实与推断；推断写清前提。
4. 与可视化、底稿交叉核对数字一致性。

## 输出

```markdown
## 现状结论
1. [现象] …；[对比] …；[支撑: 表/图/指标] …；[解读] …

## 亮点结论
1. ...

## 问题结论
1. ...

## 未达结论标准的观察（可选）
- ...
```

## 原则

- 禁止没有数据支撑的主观猜想。
- 一条结论只主张一个要点；复杂故事拆成多条。
- 数字与报告、图表保持同一口径与同一周期。
