# 衍生字段 & 指标扩充（Spec 5.4）

在清洗后的标准数据集上生成分析所需的衍生维度与指标。

## 必须覆盖的衍生类别

1. **时间维度**：年、季度、月、周、工作日/周末  
2. **增长指标**：增量、环比、同比、目标完成率  
3. **结构指标**：分项占比、TopN 贡献占比  
4. **统计指标**：平均值、中位数、极差、渗透率  
5. **分层标签**：高/中/低价值；头部–腰部–尾部  

## 工作流程

1. 确认基准：统计周期、对比期、目标值来源、分层阈值规则。
2. 列出衍生字段清单（名称、公式、依赖字段、粒度）。
3. 实现计算并抽样核对；异常结果回查分母为 0、期初缺失等。
4. 写入口径附录（字段级公式），供 `metrics-calculation` / 报告复用。

## 输出

```markdown
## 衍生字段清单
| 字段 | 类别 | 公式/规则 | 粒度 | 依赖 |

## 分层规则说明
- 高/中/低、头腰尾的切分依据

## 校验抽查
- 样例行 / 边界情况

## 输出数据集
- 数据集_清洗完成_带衍生字段_YYYYMMDD.xlsx（或等价）
```

## 原则

- 公式透明、可回溯到明细。
- 分层阈值优先用业务约定；无约定则说明默认规则并请确认。
- 同比/环比需明确对齐日历（自然月 vs 业务月）。
