# EDA 检查清单

## 结构

- [ ] 行数、列数、文件大小 / 内存占用（如可知）
- [ ] 每列 dtype；明显该是时间/类别却被当成数值的列
- [ ] 主键唯一性；复合主键候选

## 质量

- [ ] 每列缺失率与缺失模式（随机 / 成块）
- [ ] 完全重复行、业务键重复
- [ ] 异常极值、负值（在不允许时）、超出合理业务范围
- [ ] 编码/单位不一致（如 ¥ 与 $、cm 与 m）

## 分布与关系

- [ ] 数值：均值/中位数/分位数；偏态与多峰
- [ ] 类别：Top-N 与「其他」占比；高基数警告
- [ ] 时间：缺口、时区、排序
- [ ] 目标变量（如有）：类别不平衡或极端偏斜

## 交付

- [ ] 至少 3 条可行动洞察
- [ ] 明确数据质量阻塞项
- [ ] 下一步分析优先级
