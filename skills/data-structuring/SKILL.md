# 数据整理｜结构化规整（Spec 5.2）

把「能打开的表」变成「可程序化处理的结构化表」，清洗规则见 `data-cleaning`。

**模板：** `docs/templates/02-field-mapping.md`。

## 工作流程

1. **清理表格噪音**
   - 删除合并单元格、多余标题行、备注行、页脚
   - 删除空行、空列
2. **表头标准化**
   - 统一中文列名（或团队字典名）
   - 去除特殊符号、空格、换行
3. **格式统一**
   - 日期 → `YYYY-MM-DD`
   - 数值 → 纯数字（去货币符号、千分位）
   - 文本 → 去首尾空格与不可见字符
4. **多源多表**
   - 按关联键合并为总宽表
   - 保留 `数据来源` 标记字段
   - 记录合并键、一对多膨胀风险

## 输出

```markdown
## 结构化变更日志
| 步骤 | 操作 | 影响 |

## 字段映射
| 原列名 | 标准列名 | 类型 | 备注 |

## 合并说明（如有）
- 关联键 / 行数变化 / 未匹配行

## 结构化数据集路径
```

## 原则

- 输出新文件，不覆盖接收阶段备份。
- 无法自动判定的列名/键先列「待确认」，不臆造映射。
