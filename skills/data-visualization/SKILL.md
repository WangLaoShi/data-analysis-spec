# 数据可视化输出规范（Spec 5.8）

**模板：** `docs/templates/06-chart-inventory.md`。

## 图表选型

| 目的 | 图表 |
|------|------|
| 时间趋势 | 折线图 |
| 分类对比 | 柱状图 / 横向条形图 |
| 占比结构 | 饼图、环形图、堆叠柱状 |
| 变量相关 | 散点图 |

## 统一格式

- 每图具备：标题、Y 轴单位、统计周期、数据来源  
- 配色简洁，拒绝多余花哨特效  
- 拐点、关键数值高亮标注  
- 图表原图单独归档，供报告复用  

## 工作流程

1. 明确该图要回答的一个问题。  
2. 按上表选型；占比类类别过多时优先条形/树图，慎用多切片饼图。  
3. 实现并自检：单位、周期、来源、标签是否完整。  
4. 导出原图包，文件名含指标与周期。

## 输出

```markdown
## 图表清单
| ID | 问题 | 类型 | 数据口径 | 文件路径 |

## 读图要点（每图 1–3 条）
## 归档路径（原图包）
```

## 原则

- 图表与分析结论数字一致。  
- 不截断误导性坐标；双轴慎用并明确标注。
